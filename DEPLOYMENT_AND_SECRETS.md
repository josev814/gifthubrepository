# Deployment & Secrets

See the 'DEPLOYMENT_AND_SECRETS' section in project planning. Set these GitHub Secrets:
- POSTGRES_PASSWORD
- SENDGRID_API_KEY
- JWT_SECRETS (JSON)
- JWT_CURRENT_KID
- RABBITMQ_USER / RABBITMQ_PASS
- REDIS_URL
- FRONTEND_URL
- BACKEND_URL
- OAUTH_GOOGLE_CLIENT_ID / OAUTH_GOOGLE_SECRET
- OAUTH_APPLE_CLIENT_ID / OAUTH_APPLE_SECRET
- OAUTH_MICROSOFT_CLIENT_ID / OAUTH_MICROSOFT_SECRET
- OAUTH_FACEBOOK_CLIENT_ID / OAUTH_FACEBOOK_SECRET
- DOCKERHUB_USERNAME / DOCKERHUB_TOKEN

DNS entries:
- api.example.com -> backend
- app.example.com -> frontend

CSP and OAuth callback URIs described in repo docs.
